# Aktuelle Identität in den Settings bzw. im Header anzeigen

## Goal
Zeige die aktuelle Identität des Geräts in der UI an, damit der Benutzer jederzeit sieht, als welche Person er/sie gerade agiert.

## Design Decision
**Implementierung:** Aktuell gibt es keine separaten Settings. Die Identität wird im **Header neben dem Trip-Namen** angezeigt (z.B. "Kasse · Du: Max"). Das ist:
- Immer sichtbar
- Platzsparend  
- Clickable zum Wechsel der Identität (öffnet Identitäts-Modal)

Das Änderungsprotokoll zeigt bereits eine device-person Zuordnung und bleibt unverändert.

## Implementation Steps
1. Funktion `renderCurrentIdentity()` schreiben – ermittelt aktuelle Person aus `state.devices`
2. HTML-Element in brand-text für Identitätsanzeige hinzufügen
3. Event-Listener hinzufügen: Click öffnet Identitäts-Modal
4. In `render()` aufrufen
