# Persönliches Token pro Person im Raum-Datenmodell anlegen

Das Token soll zufällig, schwer zu erraten und pro Person eindeutig sein. Personen ohne Token, also auch alte Räume, bekommen beim Laden eines. Das Token darf nicht in der normalen Personenanzeige auftauchen.
