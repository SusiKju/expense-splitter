# Zahlungsinfos pro Person und Zahlungslink im Ausgleichsplan

Der Ausgleichsplan zeigt, wer wem wie viel zahlt, die eigentliche Überweisung passiert aber außerhalb der App. Pro Person soll optional ein PayPal.me-Name oder eine IBAN gespeichert werden. Im Ausgleichsplan erscheint bei jedem Eintrag ein PayPal-Link mit vorausgefülltem Betrag bzw. ein Button zum Kopieren der IBAN. Es werden nur Text und Links angezeigt, keine Zahlungsabwicklung.
