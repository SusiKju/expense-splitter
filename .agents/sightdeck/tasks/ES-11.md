# Fremdwährungen mit manuellem Kurs pro Ausgabe unterstützen

Urlaub findet fast immer im Ausland statt, die App kennt aber nur EUR. Pro Ausgabe sollen Währung und Wechselkurs angegeben werden können. Beim Speichern wird der Betrag in EUR umgerechnet, Originalbetrag und Währung bleiben zur Anzeige erhalten. Der Kurs wird manuell eingegeben, damit kein Backend und keine externe API nötig sind. Salden und Ausgleichsplan rechnen weiter in EUR.
