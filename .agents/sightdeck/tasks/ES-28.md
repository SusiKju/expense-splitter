# Theme-Auswahl nur in den Settings, Standard ist Dark

Theme-Umschalter außerhalb der Settings entfernen, sodass das Theme nur noch in den Settings einstellbar ist. Ist keine Auswahl gespeichert, wird Dark als Standard gesetzt. Eine bereits gespeicherte Auswahl der Nutzer bleibt erhalten.
