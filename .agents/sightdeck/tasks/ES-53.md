# Personenbezogene Einladungslinks erzeugen und teilen

inviteUrl() wird so erweitert, dass es zusätzlich das Personen-Token übernimmt. In der Personenliste oder im Teilen-Dialog gibt es pro Person eine Aktion zum Kopieren bzw. Teilen des Links. Der bisherige gemeinsame Link ist dafür nicht mehr gedacht.
