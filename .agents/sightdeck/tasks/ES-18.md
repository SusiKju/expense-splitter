# Einladung per Link und QR-Code statt Raum-Code

Der Beitritt über einen 6-stelligen Code ist umständlich. Es soll einen Einladungslink geben, der den Raum-Code enthält und beim Öffnen die Kasse direkt lädt. Zusätzlich wird der Link als QR-Code angezeigt, clientseitig erzeugt. Der Link lässt sich über die Web Share API teilen.
