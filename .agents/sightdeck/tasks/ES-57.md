# Commit-Messages beim GitHub-Development sichtbar machen

Beim GitHub-Development soll immer sichtbar sein, was das Thema einer Änderung ist. Die Commit-Message muss dafür sichtbar sein.

Im Repo gibt es keine GitHub-Workflows (.github fehlt). Das Problem liegt also vermutlich in der Commit-Konvention oder im Commit-Ablauf der Agents (.agent-context, .claude, Sightdeck).

Offene Fragen: Wo genau fehlt die Commit-Message (GitHub-Weboberfläche, Commit-Liste, PR, Tool)? Wie sieht ein Beispiel für einen schlechten Commit aus?
