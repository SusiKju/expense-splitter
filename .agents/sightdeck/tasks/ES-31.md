## Ziel
User lädt eigenes Bild hoch; es ersetzt Initialen/SVG-Karikatur überall (Ausgaben, Salden, Personen) und im Header-Button zu den Settings. Immer rund.

## Entscheidung Komprimierung
- Clientseitig per Canvas: mittig quadratisch zuschneiden → 128×128 JPEG q0.75 → Base64-Data-URL (~4–8 KB).
- Gespeichert als `person.photo` im State-Blob → synct ohne Extra-Pfad (anders als Belege, die mit ~400 KB eigenen RTDB-Pfad brauchen). `database.rules.json` erlaubt `state` beliebig, keine Regeländerung.
- Rund: CSS `border-radius:50%` + `object-fit:cover`.
- Sync-Daten sind untrusted → `isPhotoUrl` prüft strikt `data:image/jpeg;base64,…` bevor es ins `src` geht.

## UI
Settings-Modal („Mehr“): Feld „Dein Profilbild“ (nur mit gesetzter Identität), Vorschau + „Bild wählen“ + „Entfernen“.
