# Browser-Aufruf ohne Bestätigung dauerhaft zulassen

## Lösung

Die Browser-Automatisierung wird über Claude-in-Chrome-Tools durchgeführt. Um Berechtigungsaufforderungen zu vermeiden, wurden folgende Tools in `.claude/settings.local.json` zur Allowliste hinzugefügt:

- `mcp__claude-in-chrome__tabs_context_mcp` — aktuelle Browser-Tabs verwalten
- `mcp__claude-in-chrome__navigate` — zu URLs navigieren
- `mcp__claude-in-chrome__read_page` — Seiteninhalte lesen
- `mcp__claude-in-chrome__computer` — Browser-Interaktionen (klicken, eingeben)
- `mcp__claude-in-chrome__tabs_create_mcp` — neue Tabs erstellen
- `mcp__claude-in-chrome__tabs_close_mcp` — Tabs schließen
- `mcp__claude-in-chrome__form_input` — Formularfelder ausfüllen
- `mcp__claude-in-chrome__javascript_tool` — JavaScript ausführen
- `mcp__claude-in-chrome__gif_creator` — Screenshots/GIFs erstellen
- `mcp__claude-in-chrome__read_console_messages` — Browser-Konsole lesen

Die Allowliste in `.claude/settings.local.json` verhindert, dass diese Tools bei jeder Verwendung eine Bestätigungsaufforderung auslösen.

## Implementierung

Alle Browser-Tools wurden zur `permissions.allow`-Liste in `.claude/settings.local.json` hinzugefügt. Diese Datei ist git-ignoriert und benutzer-spezifisch.
