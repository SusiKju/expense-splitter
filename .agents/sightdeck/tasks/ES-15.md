# Abrechnung als PDF, CSV oder Teilen-Text exportieren

Aktuell kann man nur den Ausgleichsplan kopieren. Ein Export ist eine Standard-Erwartung. PDF über ein Print-Stylesheet und `window.print()`, CSV als Blob-Download der Ausgabenliste, Teilen-Text über die Web Share API mit Clipboard als Fallback. Es wird keine neue Bibliothek benötigt.
