## Ziel

Auf schmalen Mobil-Displays wird das Eingabefeld für den Preis beim Hinzufügen einer Ausgabe abgeschnitten. Das mobile Layout muss so angepasst werden, dass das Feld vollständig sichtbar ist.

## Kontext

Das Preisfeld ist ein kritisches Element im Ausgaben-Formular. Es sollte auf allen Viewport-Größen gut sichtbar und anklickbar sein.

## Implementierung

1. HTML/CSS in urlaubskasse.html prüfen
2. Mobile Breakpoints und Layout anpassen
3. Mit echtem mobilen Device oder Responsive-Mode testen
4. Sicherstellen, dass das Feld nicht abgeschnitten wird

## Definition of Done

- Preisfeld ist auf schmalen Displays (320px–400px) vollständig sichtbar
- Feld ist noch anklickbar und editierbar
- Keine optischen Brüche oder Scrolling nötig
