# Beitritt per Einladungslink setzt Identität automatisch

Beim Öffnen wird das Token aus der URL gelesen und mit den Personen im Raum abgeglichen. Bei einem Treffer ruft die App setIdentity() auf, danach wird das Token aus der URL entfernt. Ohne gültiges Token darf das Identitäts-Modal keine freie Auswahl bestehender Personen mehr anbieten. Offene Fragen: Wie verhalten sich Geräte, die schon zugeordnet sind? Bleibt die Selbstregistrierung neuer Personen erhalten?
